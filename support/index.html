SUPPORT

Account connection and local data control

Countryball Studio keeps its publishing workflow on the creator's computer. Use these steps to manage authorization and local records.

01

Connect an account

  1. Open Countryball Studio on your computer.
  2. Open the TikTok section.
  3. Select “Connect account.”
  4. Review TikTok's authorization screen and approve only the requested scopes.
02

Disconnect an account

  1. Open the TikTok section.
  2. Select “Disconnect account.”
  3. The application requests revocation and removes the local token record.
  4. You may also revoke access from your TikTok account's security settings.
03

Delete local data

  1. Disconnect the account first.
  2. Remove local publication-history and project files you no longer need.
  3. Delete rendered MP4 files separately if desired.
  4. Uninstalling the application does not delete content already posted to TikTok.
04

Remove a TikTok post

  1. Open TikTok using the connected creator account.
  2. Open the published video.
  3. Use TikTok's delete or privacy controls.
  4. Countryball Studio cannot silently alter an existing post.
